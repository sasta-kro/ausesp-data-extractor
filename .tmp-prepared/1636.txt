Abstract

This project presents a Body Weight Balancing system to be used in predicting the number of days needed for a person to get to a normal weight state based on his or her Body Mass Index (BMI), Basal Metabolic Rate (BMR), and Daily Food Intake Calorie (DIFC). By using BMI value, the system estimates the weight value of a person, where the individual with a normal BMI has a weight value of zero. Based on BMR, the Daily Needed Calorie (DNC) of a person is calculated, and from the DNC, the weight value and the DIFC, the number of days needed for a person to get a normal BMI state could be predicted. And also the presented system would recommend needed food items for a person based on his/her weight value.

1.1 Introduction
This Application presents a Weight Prediction System to be used in predicting the number of days needed for a person to get to a normal weight state based on his or her Body Mass Index (BMI), Basal Metabolic Rate (BMR), Daily Food Intake Calories (DIFC). By using BMI value, the system estimates the weight value of a person, where the individual with a normal BMI has a weight value of zero. Based on BMR, the Daily Needed Calories (DNC) of a person is calculated, and from the DNC, the weight value and the DIFC, the number of days needed for a person to get a normal BMI state could be predicted.

1.2 Rationale and Motivation	
In modern society, more and more people will get varying degrees of obesity due to lack of exercise, sedentary offices or at home. In modern medicine, obesity will bring a lot of risk, like digestive and pulmonary disease, or cardiovascular and gallbladder and diabetes mellitus. Most of times, except lack of exercise to obesity, food intake is the most important. So, we decided to design an application to determine if a person is obese, meanwhile, giving a suggestion of food intake and the predicted the number of days to achieve that person's normal weight.

1.3 Problem Statement
Early clinical studies have shown that among the chronic patients, the mortality rate of the lower BMI is higher than that of the higher BMI. The earliest was the longer survival rate in dialysis patients who were overweight and obese in 1999, Nursing-Home elderly residents and chronic obstructive pulmonary disease (COPD) patients observed this phenomenon, which is called the obesity paradox.
In recent years, the elderly also found this phenomenon. However, according to the National Nutritional Health Survey, the low risk of death from BMI observed in the elderly population is since low BMI reflects relatively low muscle mass and low BMI also reflects low muscle mass (or muscle loss Disease) health risk. 
BMI is proportional to the mass and inversely proportional to the square of the height. So, if all body dimensions double, and mass scales naturally with the cube of the height, then BMI doubles instead of remaining the same. This results in taller people having a reported BMI that is uncharacteristically high, compared to their actual body fat levels. In comparison, the Ponderal index is based on the natural scaling of mass with the third power of the height.
However, many taller people are not just "scaled up" short people but tend to have narrower frames in proportion to their height. Nick Korevaar [3] (a mathematics lecturer from the University of Utah) suggests that instead of squaring the body height (as the BMI does) or cubing the body height (as the Ponderal index does), it would be more appropriate to use an exponent of between 2.3 and 2.7. 1.5 Goals and Objectives
The goal of this project is to design a system that can calculate a person's Body Mass Index (BMI) to judge whether a person is in normal weight, then based on Basal Metabolic Rate (BMR) and a person's lifestyle, automatically select food and according to a certain number of days to achieve the normal weight.
Our goal is divided into three objectives:
1. To develop an algorithm that can calculate how much calories needed to achieve the normal weight.
2. To design a framework that can recommend food, based on lifestyle and Daily Food Intake Calories (DIFC).
3. To develop a client-service application with clear presentation of calculated result.

W = BMI (normal) * (height) * (height),						(2)

3.2.5 Prediction of days
There is noted hereby that 1 pound (or 0.443592kg) of fat is equal to 3500 calories. To reduce weight by 1, pound a week that would require a person to create a deficit of 3500 calories (it means that deficit 500 calorie daily in 7 days). This is to say, for one to lose more weight needs to simply create a bigger deficit.
To add weight by 1, pound a week that would require a person to create a deficit of 3500 calories (it means that deficit 500 calorie daily in 7 days). This is to say, for one to add more weight needs to simply create a bigger deficit.
To find out the number of calories needed to reduce the extra weight of an overweight person, predict the number of days to attain the desired weight or state of a normal BMI, BMR, DNC, and DIFC and overweight value (or lower weight value), the system just uses any value from overweight min (or lower weight max) to calculate the required days to achieve the desired weight. The predicts the number of days for an overweight person who desired to attain a normal BMI status by subtracting 500 calories from DNC value and then multiplying it with 7 to get a reduction of 0.45392kg weight per week as expressed below:
(DNC - 500) * 7 = 0.453592 kg. 							(11)
If DIFC is less than DNC - 500, then the Percentage Reduction in Calorie(PRC) could be calculated, (otherwise a person would not be loss weight, it means the system will not be able to predict the number of days:
PRC (Percentage reduction in Calorie) = (((DNC-500) - DFI) / (DNC-500)) * 100. (12)
Based on Eqs. (11) and (12), the Earned Weight Reduction (EWR) value of the person can be calculated as:
EWR (Earned weight reduction) = 0.453592 * PRC.					(13)
Based on Eq. (13), the overall Weight Reduction (OWR) value of the person which can be calculated as:
OWR (over weight reduction) = 0.453592 + EWR. 					(14)
From Eqs. (4) and (14), The Minimum Number of Days Needed (NDN min) for a person to reduce his or her weight to reach in a state of normal BMI, the formula is shown below as:
NDN (Minimum number of days needed) = overweight (min) / (or/7). 		(15)
Similarly, the system can predict the number of days required to reach normal BMI for a low weight person with no eating disorder, in such case, the DNC value add 500 calories and then multiply it with 7 to get an addition of 0.453592 kg weight per week which is also shown below:
(DNC + 500) * 7 = 0.453592 kg.							 (16)
If DIFC is greater than DNC + 500, then the Percentage Addition in Calorie (PAC) could be calculated, (otherwise a person would not be adding weight, and it means the system will not be able to predict the number of days.
PAC (Percentage Addition in Calorie) = ((DIFC-(DNC+500)) / (DNC+500)) * 100. (17)
Based on Eqs. (16) and (17), the Earned Weight per Week (EWW) value of the person can be calculated as:
EWW (Earned weight per week) = ((0.45392 * PAC)/100) + 0.45392.		 (18)
From Eq. (18), The Minimum Number of Days Needed (NDN min) for a lower weight person to reach a normal BMI and it can be given as:
NDN (Minimum number of days needed) = lower weight (min) / (EWW/7).		 (19)

3.5 Problems and Solution
1. Boundary value problem (BMI)
We encountered a problem dealing with BMI values, such as the maximum BMI which have the normal boundary of 24.9, if a person's BMI value is exactly 24.9, the system cannot be displayed.
Solution: Because we are accurate to the last three digits at the exact decimal point, and if not, we can solve the problem. The way we solve it is that we have only 1 digit.
2. Exception handling (connect to SQL)
After ping ip address, if we connect to a database on another computer, it works, but after a while, the connection was unsuccessful.
Solution: Because in the same network environment, ip address changes often, so we switched to the use of the computer's name to connect to solve this problem.
3.The rationality of calculation (select food DIFC)
We have considered if we should arrange the food without dividing it. If so, the performance of the computer running is important because the computational complexity of permutations and combinations is huge. Moreover, after the calculation of the results may be impractical, such as breakfast arranged to eat watermelon, and extra food like pizza.
Solution: Divide the food into 4 parts: breakfast, lunch, dinner and extra food. According to the normal life, the ratio is 3:5:4:1. Different time used different tables. (Because lunch and dinner are similar, so they used common tables).
4. Calculate the time of the result, Improve performance (DIFC)
Calculate the results estimate about 12 seconds, regardless of the large amount of computation and computer performance factors, we still think that it takes long.
Solution: After permutation, sort lunch and dinner first. The result is positive, only about 7 seconds to finish. Another solution is we can arrange the data in the database first. However, the disadvantage is that if we change the contents of the table (input more data or delete data), the solution fails.
Best solution (right now we are using): Thread. We use this method to handle permutation and combination, meaning we start the computation as soon as the App starts.
5. Runtime error (DIFC)
The result is not correct under normal weight status, but overweight and lower weight are okay.
Solution: No initialization.

            DataTable BreakfastDt = GetSuggestDataForSevenDays(FormMain.BreakfastDataListByOrderDt, BreakfastCalories);

            dataGridViewResult.Columns["Lunch"].Width = 250;
            dataGridViewResult.Columns["Dinner"].Width = 250;
            dataGridViewResult.Columns["Others"].Width = 200;
            dataGridViewResult.Columns["TotalCalories"].Width = 80;

            double SumCalories = 0.0;
            for (int i = 0; i < DtResult.Rows.Count; i++)
                SumCalories += Convert.ToDouble(DtResult.Rows[i]["TotalCalories"]);
            double DFI = Math.Round(SumCalories / 7, 1);

            int NDN = 0;
            if (FormMain.BodyStatus == "OverWeight")

                double PRC = (SuggestionCalories - DFI) / SuggestionCalories;
                double EWR = 0.45392 * PRC;

                NDN = Convert.ToInt32(FormMain.OverWeight / (OWR / 7));
                labelResult.Text = "Your average calorie is " + DFI.ToString() + " calories. If you following this recommendation, you need " + NDN.ToString() + " days to attain healthy weight status.";
            }
            else if (FormMain.BodyStatus == "LowerWeight")
            {
                double PAC = (DFI - SuggestionCalories) / SuggestionCalories;
                double EWW = 0.45392 * PAC / 100 + 0.45392;
                NDN = Convert.ToInt32(FormMain.LowerWeight / (EWW / 7));
                labelResult.Text = "Your average calorie is " + DFI.ToString() + " calories. If you following this recommendation, you need " + NDN.ToString() + " days to get healthy weight status.";
            }
            else
            {
                labelResult.Text = "Your average calorie is " + DFI.ToString() + " calories. If you following this recommendation, you will keep healthy weight status.";
            }



        }

        private DataTable GetSuggestDataForSevenDays(DataTable DtSourceByOrder, double SuggestCalories)
        {
            DataTable SuggestData = new DataTable();

            int NearestRowNum = 0;
            for (int i = 0; i < DtSourceByOrder.Rows.Count - 1; i++)
            {
                if (SuggestCalories >= Convert.ToDouble(DtSourceByOrder.Rows[i]["Calories"]) && SuggestCalories <= Convert.ToDouble(DtSourceByOrder.Rows[i + 1]["Calories"]))
                {
                    if (FormMain.BodyStatus == "OverWeight")
                        NearestRowNum = i;
                    else if (FormMain.BodyStatus == "LowerWeight")
                        NearestRowNum = i + 1;
                    else
                        NearestRowNum = i;
                }
            }

            SuggestData.Columns.Add("EatableName", typeof(string));
            SuggestData.Columns.Add("Calories", typeof(double));
            for (int i = 0; i < 7; i++)
            {
                if (FormMain.BodyStatus == "OverWeight")
                {
                    SuggestData.Rows.Add(DtSourceByOrder.Rows[NearestRowNum]["EatableName"], DtSourceByOrder.Rows[NearestRowNum]["Calories"]);
                    NearestRowNum--;
                }
                else if (FormMain.BodyStatus == "LowerWeight")
                {
                    SuggestData.Rows.Add(DtSourceByOrder.Rows[NearestRowNum]["EatableName"], DtSourceByOrder.Rows[NearestRowNum]["Calories"]);
                    NearestRowNum++;
                }
                else
                {
                    SuggestData.Rows.Add(DtSourceByOrder.Rows[NearestRowNum]["EatableName"], DtSourceByOrder.Rows[NearestRowNum]["Calories"]);
                    NearestRowNum += Convert.ToInt32(Math.Pow(-1, i + 1)) * (i + 1);
                }

            }

            return SuggestData;
        }
        private static DataTable GetCaloriesByOrder(DataTable DtDataList)
        {
            string SwapEatableNameTemp = "";
            double SwapCaloriesTemp = 0.0;
            for (int i = 0; i < DtDataList.Rows.Count - 1; i++)
            {
                for (int j = i + 1; j < DtDataList.Rows.Count; j++)
                {
                    if (Convert.ToDouble(DtDataList.Rows[j]["Calories"]) < Convert.ToDouble(DtDataList.Rows[i]["Calories"]))
                    {
                        SwapEatableNameTemp = DtDataList.Rows[j]["EatableName"].ToString();
                        SwapCaloriesTemp = Convert.ToDouble(DtDataList.Rows[j]["Calories"]);

                        DtDataList.Rows[j]["EatableName"] = DtDataList.Rows[i]["EatableName"];
                        DtDataList.Rows[j]["Calories"] = DtDataList.Rows[i]["Calories"];

                        DtDataList.Rows[i]["EatableName"] = SwapEatableNameTemp;
                        DtDataList.Rows[i]["Calories"] = SwapCaloriesTemp;
                    }

                }
            }
            return DtDataList;
        }
