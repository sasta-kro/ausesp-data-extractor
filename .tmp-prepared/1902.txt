1.Introduction

Today, we live in a world that called the internet’s world which
everything is connected to the internet. Everywhere and every time we
are connecting to the internet without acknowledgment. The internet
connection is an amazing thing, it gives us all sorts of benefits that
we can’t imagine that before. In the past, we had a cellphone and now we
have a smartphone. You could call and you could text, but now you can
watch any movie, read any book, or listen to any song any time you want.
The point is that when connected to the internet and people connect to
the internet, you and other people are the same places. You can share
the knowledge or contact with them even you are the other side of their
country.

IoT or Internet of Things means taking all the things in the world and
connecting them to the internet. By combining these connected devices
with automated systems, it is possible to gather information, analyze it
and create an action to help someone with a particular task or learn
from a process. When something is connected to the internet, that means
it can send information or receive information, or both. This can make
things smart. IoT offers the opportunity to be more efficient in how we
do things, saving time, money and often emissions in the process. IoT
can be implemented to the business model and help a business go well and
more efficient.

POS or Point of sale. The point-of-sale is what takes place between a
merchant and a customer when a product or service is purchased, commonly
using point of sale system to complete the transaction. POS is a part of
IoT which connect multiple devices and work over the internet. The POS
system is synonymous with the POS terminal. However, the POS terminal is
the electronic equipment performing the sales transaction and processing
the credit card or cash payment. It can combine with a barcode scanner,
recipe printer, keyboard, mouse, and etc. POS terminal can’t run it by
itself, it must have POS software to run it and now you have the full
definition of a POS system. A point of sale system is the heart of a
business and used for many essential tasks such as inventory management,
labor reporting, menu customization, price adjustment, and so much more.

Tax invoice system is a system that I’m focusing on it and use IoT and
POS to improve the system. I decide to use Rasberry Pi, a tiny credit
card size computer. Just add a keyboard, mouse, display, power supply,
micro SD card with installed Linux Distribution and you'll have a fully
fledged computer that can run applications, as a small computer to run
my software. It’s cheap, small, and it can run the software the same as
an ordinary computer.

2.Statement of Problem

- Complexity of system

  Scenario: In the gas station, there are many customers come to fill
  the gas and most of them want a tax invoice. With the current system,
  it uses many processes to accomplish one tax invoice receipt. It means
  more customers, more processes to be done. It causes a slow system

- Handwork and ability of the employee

  Scenario: Some of tax invoice receipt still use a paper base and write
  it by a human. It makes processes slower than use system to process.
  Moreover, most of the employees are not familiar with technology and
  complicated system. I will make the process, even more, slowly and not
  as effective as it is.

- High cost

  Scenario: The current system use one-time purchase, it means the
  system will be sold only one time and maintenance costs aren’t
  included in that cost. Thus, when the system is failing, you have to
  pay the cost of it and the cost is count 5 baht per kilometer.

  product’ name and product’s price.

  Scenario: When the product’s price or the gas’ price change, the

- The software should be able to keep the tax invoice record in case of
  customer want to see the previous tax invoice

  Scenario: When a customer loss his/her tax invoice receipt, the

  show it to him/her

- The software should be able to search the company tax id for customer
  so the employee doesn’t require to write all information

  Scenario: The API from The Revenue Department is helpful to
  automatically search the information from tax id so the employee
  doesn’t write all information to software.

- Function 5: Price tax invoice receipt

- The software should be able to print the tax invoice receipt when the
  customer wants the tax invoice receipt.

  Scenario: This software is focusing on printing tax invoice receipt so
  printing the tax invoice receipt correctly and the software should be
  ready to print to the customer anytime.

6. Limitation

For this software which is written by Python and there is some
limitation in it for the GUI of this software. In addition, some
limitation of the software itself needs to be noticed by the employee.
Limitation of tax invoice software is listed as follows:

- Limitation 1: The GUI is different in each device due to Tkinter

- This software uses Python and the GUI for the software is Tkinter
  which is the GUI part of Python. The Tkinter has a big weakness which
  is the GUI include font, font size, and more will be changed depending
  on the device or platform. When we use it on the window it might be
  fit and smooth but when we use it on Raspberry Pi or even different
  window, the GUI will be changed and every element will be mess up.

- Limitation 2: The gas’ price need to change manually

- This software isn’t automatically updated the gas price so the
  employee needs to change the gas price manually.

- Limitation 3: The Revenue Department API issue

- Sometimes The Revenue Department API doesn’t load the information and
  sometimes their server is down so searching function might don’t work.

- Limitation 4: The environment factor which affects to Raspberry Pi

- Raspberry Pi is a sensitive device with heat. Without heat sink, the
  CPU is quickly heating up and it might turn up to shutting down of
  Raspberry Pi. Moreover, it’s small and lightweight, it might be broken
  when it falls or crushes to something.

7. Methodology

Tax invoice system is developed base on Agile methodology due to I’m the
only person who develops this system. It’s quite easy to manage the
process of this methodology. The processes begin as follows:

- Getting requirement

- In this phase, I discuss with the project advisor and get the
  requirement from him. Discuss the issue and find the solution to those
  issues

- Planning

- After I did discuss with project advisor, it’s time to plan what I
  should do next and what problem should be fixed first. Prioritize the
  problem and find the solution for it.

- Design

- It’s the phase that I make the prototype and design the UI/UX for the
  tax invoice system. This phase might take time to finish since the
  prototype might not fit the requirement and the requirement might be
  changed all the time.

- Develop

- This phase’s all about coding the software. Fixing bug is the part of
  this phase as well. However, we get all requirement but it might be
  changed along with this phase so this phase is the longest phase of
  this methodology. The next phase might be going back to Getting
  requirement phase to get a new one.

- Release

- After I finish coding and make the software works, it’s time to
  implement this software to the real world.

- Track & monitor

- After implement to the real world, I will track the error or some
  strange problem which might occur unintentionally so I can list it and
  get back to the first phase, Getting requirement.
