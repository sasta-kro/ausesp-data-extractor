Abstract

Time series analysis is the main tool used for predicting the future in
various areas and especially in financial. From stock market to number
of users or amount of sales, various tools and method are applied to
time series data to assist in choosing the best decision to make. The
goal of this work is to predict the amount of sales quantity of various
menu from a Thai franchise restaurant. In order to do so, we tested a
total of 7 different approaches of how to get the best prediction. This
includes matching item from each menu’s attributes, using Jaccard
Similarity to find the most similar menu then forecast using one item or
combine forecast of a few item then get the average. All forecasts are
done in using Holt-Winters for its simple yet powerful capability.
Various type of ways to calculate the score was implemented to see which
way is the best for calculating match for forecasting. The result is an
indication of which menu will be the best seller or customers favorite,
so the restaurant can focus on integrating it into their promotions.

1. Introduction

The current state of restaurant market in Thailand is very competitive
where everyone is trying their best to attract customers using various
tools and strategy from traditional to digital ads or running nonstop
promotion all year round. All these promotions come in all shapes and
forms whether it is traditional way of advertising through TV, radio,
posters and billboard, or new ways of advertising through social network
platform such as Facebook, Instagram and YouTube. Whatever the type of
advertisement is, all companies are trying their best to get customers
to see what they have to offer and this is especially true for a big
Thai franchise restaurant that not only have to compete with other local
restaurants, they also face a lot of competitions from international and
well known brand from other countries as well. That is the reason why
when they run promotions on their advertisement, they need to constantly
change it up and not repeating the same promotion all the team or their
customers will not be interested in going or returning. One of the
biggest challenges in doing so is the uncertainty of how well each
promotion will do and what is the cause of the increase or decline of
sales.

The main contribution of this work is to experiment with different
technique to predict the sales of new promotional menu without any
historical sales data of that exact menu but instead use different menus
that have similar items. The dataset was used in training and testing on
one of the most simple but versatile algorithms for time series
analysis: Holt Winters. Holt Winters is one of the techniques used to
smooth time series data and it is also known as Exponential Smoothing.
We also need a way to collect all the similar menu for forecasting and
one way we did is by choosing all the menus with the same attribute and
we do this for all five available attributes. Another way is to use
Jaccard Index. Jaccard Index is used to measured similarity of sample
sets, so it is suitable to use with our data since each individual menu
also has their own attributes that we can use to measure similarity.

2. Related Works

There are a lot of works that focus on forecasting using holt winters
already but most of them are focusing on forecasting using existing
historical data to predict the same thing or item. There are also a few
other works focusing on measuring similarities between items using
various methods while there are also a few works focusing promoting
cold-start item.

2.1 Forecasting

There are a lot of works done using Holt-Winters before but the major of
recent works do not focus on Holt-Winters alone anymore and they always
try in some way to combine some other method to improve results from
Holt-Winters. Getting parameters right in Holt-Winters is tricky which
is why we saw other studies done using M-estimation to select parameters
[1]. Parameters are always updating then robustified when they get good
results. Another similar work was done but using bootstrap approach to
analyze the performance instead. They both manage to squeeze better
results than using just regular Holt-Winters for forecasting [2].
Weighted Moving Average was also used but it was used with Double
Exponential Smoothing by calculating the weighting factor. They did get
good result from this method by testing on Jakarta Stock Exchange [3].

There are also a lot of other works done on forecasting without
Holt-Winters as well as shown in this this work that was published in
Applied Science Journal and they make uses of Moving Average,
Autoregressive Integrated Moving Average and Sigma-pi Neural Network
[4]. They did get a good result out of it with low errors measured by
MAE, MAPE and RMSE. The best performer was the one done with Sigma-pi
Neural Network with lower MAE, MAPE and RMSE than all the other 3
methods.

Different methods will return different results and all those results we
got are only as good the experts that use and interpret it as study that
was done using Bass model and Scan*pro suggested [5]. Those experts
involved can also use other software in this type of this forecast where
they select categories to focus on and then apply to Sales BI software
and it still return improvement on their previous results [6].

2.2 Similarity

In a study done by Guilherme Alves, Miguel Couceiro and Amedeo Napoli,
Adjusted Rand Index was used to measure similarity. Even though they
study did return a decent result, they still think they need to do more
research, and this is just the beginning [7]. Another study done in The
Department of Computer Science and Engineering of University of
Minnesota also came to the same conclusion when they try to find which
similarity measure is the best suited for data mining. Their result
showed that there is no best method [8].

2.3 Cold Start Problems

Some studies focus on getting results while others only focus on getting
seasonality of their unknown forecast. A study published on PLOS One
Journal was done in a company suggested that linking new item with less
active user return a better performance [9]. They did the experiment
using item-based collaborative filtering systems. Another study done in
the University of Washington suggested that combining High-dimensional
regression and matrix factorization on different kind of scenarios:
long-range, cold-start, warm-start, works well at capturing seasonal
structure of the data set [10].

The biggest differences from our current work compared to works
mentioned above are the type of forecasting we need to do. The majority
of studies mentioned above are focusing on forecasting the same item
again and try to improve their accuracy, but our work is focusing on not
only good accuracy, we also need forecast the sales of menu with little
to no history while only using similar item.

3. Theoretical Background

3.1 Forecasting Model

For forecasting model, we select Holt-Winters. It is decades old, but it
is still one of the most popular forecasting methods out there due to
its simple yet powerful capability to forecast time series data. It
utilizes exponential smoothing to encode values in the past and uses
them to forecast the values for the future. It can handle lots of
complicated seasonal patterns by simply finding the central value, then
adding in the effects of slope and seasonality. It should be noted that
in order to generate an effective Holt-Winters model, it requires
parameter tuning, which is a time consuming task.

Holt-Winters:

yt + h|t = 𝓁t + hbt + st + h − m(k + 1)

𝓁t = α(yt − st − m) + (1 − α)(𝓁t − 1 + bt − 1)

bt = β * (𝓁t−𝓁t − 1) + (1 − β*)bt − 1

st = γ(yt−𝓁t − 1 − bt − 1) + (1 − γ)st − m

3.2 Similarity Measure

There are various ways to measure similarities between different
variables. It calculates similarity between sample sets which is perfect
for our use since we can use it to measure similarity between each menu
based on the 5 columns that each menu has.

Jaccard Index:

$J(A,B) = \ \frac{|A \cap B|}{|A \cup B|}$ Eq. (x)

Using the formular above, we can get the score for how much similarity
each menu has with other menus and we can use that information to
organize or rank the similar item then use the best one for forecast.

3.3 Evaluation Measure

We also need a way to measure whether our forecast perform well or not,
and there are a lot of evaluation tools that are commonly used in these
type of time series forecasting such as Error, Bias, Mean Absolute Error
(MAE), Mean Absolute Percentage Error (MAPE), Mean Squared Error (MSE)
and Root Mean Squared Error (RMSE). We decided to choose MAPE and RMSE
to evaluate the performance of our forecast.

We choose MAPE and RMSE because they are the most two commonly used
indicators to measure forecast accuracy and quite well known among
business managers as well which is also useful for our case of
forecasting restaurant menus. MAPE is an average percentage of errors.
On the other hand, RMSE measures how far off our predictions are from
the actual testing values. It is known to assure an unbiased forecast,
but it means it is also sensitive to outliers. We use both RMSE and MAPE
to ensure that we can accurately evaluate our model’s performance and
accuracy. The formula of RMSE and MAPE are given in Eq. y and z,
respectively.

$MAPE = \ \frac{\sum_{}^{}{\frac{|A - F|}{A}\  \times \ 100}}{N}$ Eq.
(y)

$RMSE = \ \sqrt{\sum_{i = 1}^{n}\frac{{(ŷ_{i} - y_{i})}^{2}}{n}}$ Eq.
(z)

4. Proposed Methodology for Holt-Winters Forecasting

We predict the sales quantity of the new menu by using similar menus
from the past. We measure the similarity based on a categorical
attribute and rank them using Jaccard Similarity. We then collect all
the item with the same Jaccard score to predict the value then get the
average result of forecast. Root Mean Square Error (RMSE) and Mean
Absolute Percentage Error (MAPE) is used to measure the performance or
accuracy of the prediction.

In order to make data usable we need to first parse the date properly in
only one format since our data has mixed date formats and use it as our
index column. Then we go through all the columns to see all the
different unique value in each column to see if there is any missing
data. We found 3 columns with missing data and we fill the missing value
based on the ingredients name. Lastly, we added another column for main
ingredient and fill it based on item names because we need this column
to improve the accuracy when selecting similar menu.

We have a total of 7 approaches. For approach 1 to 5, we match each
attribute instead and find all the item with matched attribute, forecast
the result, and collect the average of those results.

For approach 6 and 7, we apply Jaccard index similarity on 5 columns to
get the most similar item for us to predict. Generally, several similar
items will be returned, and we need to find a way to use all of them for
forecasting. In approach 6, we select the one with the highest score for
forecasting. If there are multiple one with the same scores, we select
only one. And in approach 7, we decided on forecast with one item at a
time, then get the average of all the forecasting results from all the
items and that will be our forecasted results. We then calculate the
accuracy or performance by using MAPE and RMSE.

5. Experimental Results

The datasets are 2018 and 2019 sales of a Thai franchise restaurant. The
datasets contain 8 following attributes: item name, date, quantity sold,
gross sales, dish type, kitchen type, item type and item subtype. In
addition, we added main ingredient attribute in to improve the accuracy
of Jaccard score. The data we used is extracted from only branch
focusing on only one type of promotion only.

using main ingredient and a few in approach 4 using item subtype. The
reason of this missing value is that the menu has no match in that
category, so it means that the menu is the only menu in that subtype or
main ingredient.

If we look at both RMSE and MAPE in tables above, we can see that
approach 2 using kitchen type return the best result followed closely by
dish type and item type. Our approach 7 using Jaccard index and average
value of all matches return decent results and better than approach 6
but it is still not good enough in this case. The reason why approach 2
perform the best could be that all those item that are cooked together
in the same kitchen have more similarities than item with the same dish
type or even item type and therefore, it is a better predictor. Item
with the same dish types can have too many varieties too and the same
can be said about item type, and we can clearly see that here that even
though they have enough similarity to return good result, predictions
from item in the same kitchen is still the best out of all of them.

6. Conclusion

Holt-Winters is still widely used in time series analysis for the reason
we have shown above. It is simple to use and highly flexible while
returning good results. That said, the most time consuming and
unpredictable part about Holt-Winters is that it is very difficult to
pick the right parameters for the best possible results.

Our work did show some way to forecast and get good results using
Holt-Winters. The first 3 approach showed that matching item with the
same dish type, kitchen type, and item type return the best forecasting
result. Using 2 Jaccard Index did return decent results, but it is still
not good enough and lack behind the 3 methods mentioned before. A lot of
improvement can still be made in parameters selection or data selection.
Different types of seasonal period are still yet to be experimented and
other method of data preprocessing can still be applied to get better
result as well. For Jaccard Index, there are also some other ways of
selecting attributes for calculation that are yet to be explored.

Future research can focus on weekday, weekend seasonality or specific
day of the week when forecasting. Moreover, the same can also be done on
Jaccard Index by selecting fewer attributes or selecting it
conditionally. These are some of the way that can be done to improve the
forecasting results.
