Abstract

This paper introduces the application – Slip Salary – that is
alternative solution to handle payment of employees in selected
organization. The application uses simple structure in order to fulfill
its objective. Using Firestore as database with suitable amount of data,
this affects not only the database structure will be simple but also the
cost will be deducted. Including React.js for application side, The
well-known web development tool with several benefits. As a result, Slip
Salary is able to complete its assigned features: management, providing
printing format.

Chapter 1: Introduction

1.1 Problem Statement

Slip Salary is created to be an alternative solution to the previous one
which using Microsoft Access to get the work done. However, using
Microsoft Access can have numbers of drawback. According to user, MS
Access license cost is quite considerable amount to continuous pay.
Apart from that, the program is not flexible since its keep everything
in a single file and it is difficult to maintain. Therefore, the
solution is designed to achieve those disadvantages.

1.2 Scope of the project

The project functions are the same as what the previous solution are.
There are several features that are needed to complete this project.
First, the application must be able to manage other information which
relate to payroll at the end of the application process. Those
information are employees, payroll period, earning deductables, and
holidays. They must be manageable CRUD(create, read, update, delete). In
each topic, there are sub detail for example an employee record includes
employee number, account number, name, position, income rate, pay
period. Some of information are not required in payroll at all but they
are included in case of future demand. The key feature is to create
payroll. Providing form to fill information and produce “ready to print”
payrolls are required.

Chapter 3: Proposed Solution

3.1 Proposed Solution

The problem is to create the solution with reduced cost, flexible and
easier to maintain. Therefore, the proposed solution is the application
that using open-source React as frontend and Firestore as backend. By
using these two apply with small business amount of data, the cost of
application will be removed. In addition, this application is deployed
in Firebase along with realtime-database in Firestore. Hence, user can
access both application and database online. Additionally, Firestore
keep user’s data as document-oriented database which suitable for simple
data of small business.

3.2 ROI 

In case of this project, the return of investment can be calculated
involved the app that will be replaced. The user design to cut their
cost of Office license but they currently need Microsoft Access to do
their job. In occasion that this project can done its job properly and
can replace Microsoft Access, the yearly license cost will be deducted.
The time that user need to spend on filling form will not be different
from the previous solution since, the design of an application is intent
to be similar. Then, time using is not change. In summary, this project
can reduce cost without spending any cost.

Chapter 6: Conclusion

The project achieves as alternative payroll solution that fulfill
Microsoft Access disadvantage at selected organization and able to
remain the same require features as previous solution. However, there
are many features and improvement can apply in this project in farther
development. Those features can be found in related work. The most
obvious improve possibility are “more automatic less manual” and “add
more related features”

More automatic less manual

The current version of the project, there is many fields that should be
auto calculated or easier for user to use such as calculated tax, auto
generate pay period, auto amount calculation. However, the project
cannot apply those features in selected company. Hence, they are for
future improvement.

Add more related features

Payroll system is related to several fields for example: employee
scheduling, accounting, information analysis, employee attendance,
connect to bank account and so on. These are possibility that can be
seen from existing solution used by several medium to large company.

Even though, this project solution is enough to handle small business
that has little amount of data but there is still room for more
development in the future.
